看看它证明了什么
SCROLL

这个 demo 每一处都在"炫技"

单文件、零依赖。下面这些不是堆砌,而是每项都可单独拿出来讲清楚原理的硬功底。

CSS 3D

preserve-3d 分层视差

perspective + translateZ 把玻璃卡分到不同深度,指针驱动 rotateX/rotateY,产生真实视差,非 transform 模拟。

CSS Houdini

@property 色相动画

注册 --hue 为 <angle> 自定义属性,极光 30s 平滑变色——普通 CSS 变量无法做过渡动画,这是 Houdini 才能。

合成与混合

极光 = 4 层 radial + screen + blur

多层径向渐变以 screen 混合 + 70px blur + saturate,纯 CSS 拟出流体极光,无任何图片/视频。

Canvas

星图 + 指针视差

rAF 驱动的粒子场,按深度差异化视差偏移,近邻粒子连线成星座,devicePixelRatio 自适应。

Scroll-Driven

animation-timeline: view()

卡片揭示用最新的滚动驱动动画 API,浏览器原生 распис,无 JS 库;旧浏览器 @support 回退到 IntersectionObserver。

可访问性

prefers-reduced-motion

尊重系统"减少动效",自动停掉极光/浮动/粒子,内容仍完整可读——炫技但不失职业素养。
